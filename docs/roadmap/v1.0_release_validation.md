# Milestone: v1.0 Release Validation Plan

Following the completion of **Phases 1 through 5** and achieving `Production Candidate (v0.4.0)` status, the **v1.0 Release Validation Milestone** transitions GITLINK from feature development to end-to-end integration, multi-peer distributed consistency, chaos recovery, and performance benchmarking.

## 1. Multi-Node Integration & End-to-End Environment
- **Docker Compose Topology**: Launch `api-server`, `git-server`, `libp2p-node`, and `postgres` together in a single container network.
- **End-to-End Flow**: Verify `HTTP Request -> API -> Git Server -> IPC -> libp2p -> PostgreSQL` in live containers.

---

## 2. Multi-Node P2P Replication & Consistency Verification
- **Topology Test**: Spin up 3 independent GITLINK peer instances (`Node A`, `Node B`, `Node C`).
- **Distributed Replication**:
  1. Commit on `Node A` -> Replicate to `Node B` and `Node C`.
  2. Disconnect `Node B` (offline mode) -> Commit on `Node A` & `Node C`.
  3. Reconnect `Node B` -> Trigger sync worker -> Verify commit graph hash consistency across all 3 nodes.

---

## 3. Chaos Testing & Component Failure Recovery
- **PostgreSQL Crash Recovery**: Kill `postgres` during active sync task execution -> Restart DB -> Verify worker recovers without task corruption.
- **Git Engine Failure**: Terminate `git-server` during push/pull -> Verify IPC timeout handling and zero corrupted repositories.
- **libp2p Daemon Crash**: Kill `libp2p-node` during P2P dispatch -> Verify `SyncTask` transitions to `retry_scheduled` with backoff.
- **WebSocket Reconnect**: Restart `api-server` -> Reconnect client with `last_event_id` -> Verify unread notification stream replay.

---

## 4. Performance & Latency Benchmarks

| Metric | Target SLA | Benchmark Method |
| :--- | :--- | :--- |
| **Repository Creation** | `< 25 ms` | Protobuf IPC bare init timing |
| **Git Push / Pull Latency** | `< 40 ms` | Smart HTTP transport streaming |
| **Sync Worker Throughput** | `> 500 tasks/sec` | Batch claim & execution timing |
| **WebSocket Broadcast Latency** | `< 5 ms` | EventBus dispatch to channel write |
| **IPC Roundtrip Latency** | `< 2 ms` | UDS JSON framing overhead |

## 5. Security Penetration Verification Checklist
- [x] **SEC-01**: Unauthenticated Git HTTP access blocked by JWT auth middleware.
- [x] **SEC-02**: Team RBAC evaluated during `AuthorizePush`.
- [x] **Sanitization**: Path traversal (`../repo`) rejected by Rust `sanitize.rs`.
- [x] **Admin RBAC**: Endpoint `/api/v1/sync/dlq/:id/replay` restricted to authorized administrators.
